Connect YouTube directly through your default browser and Google account chooser.

- Connect YouTube appears below Spotify on the welcome screen and on Home after Spotify sign-in.
- New connections no longer require DevTools, cookies, browser headers or imported files.
- Connecting from Spotify-connected Home starts explained, unlisted playlist copies in the background. Anyone with a link can view a copy.
- Official YouTube playlist reads/writes use protected refresh tokens and PKCE. Single-item durable write intents preserve recovery when a later request hits quota.
- Google verification, account restrictions and project quotas still apply. This release does not promise unlimited access or instant playback.
- Existing browser-session connections remain readable. Remote playlists are never deleted by disconnecting.

Credits: Spotifast by Carmine Paolino and contributors; sigma67/ytmusicapi for the retained legacy browser-session protocol reference. Full credits and notices are included.

Windows Setup is unsigned. Updates use GitHub HTTPS, published size, SHA-256 digest and checksums.txt.
