# Vibefy 0.4.14

Listen Together is built in, and the classic mini player now carries Vibefy branding.

## New

- **Listen Together beside Lyrics.** The existing Users icon opens Host and Join without installing a mod. Sessions remain opt-in, for trusted LANs or VPNs.
- **Cat Jam size control.** Installed Cat Jam offers 50–200% scaling and Reset size, with a 90% default. The original animation touches the window edge.

## Fixed

- Lyrics provider, sync status and optional provider connection are grouped compactly at the top left.
- The mini player says VIBEFY, uses cyan accents and the actual Vibefy icon, preserving classic controls and integer pixel scaling.
- Removed custom skin selection, skin imports, folder browsing, Skin Museum and random skin workers. Existing settings migrate without resetting other preferences.
