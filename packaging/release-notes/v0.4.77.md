# Vibefy 0.4.77

- Save to YouTube checks the existing copy before updating it. A missing copy can be recreated by an explicit Save action after checking the connected library.
- Background sync does not recreate removed playlists. Connection, permission and service failures preserve the existing link.
- Updates add missing songs only. Songs already present on YouTube, YouTube-only additions and their order are preserved.
- Keep cached recording matches when recreating a removed copy. Show save progress beside the playlist and allow retry after failures.
- Web and phone saves also check the previous YouTube copy. Unconfirmed creations keep a local recovery marker so retries look for the created playlist before sending another create request.

Windows installers are not code-signed. Hosted phone changes do not require reinstalling APK/IPA.
