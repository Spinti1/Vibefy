Vibefy 0.4.52 improves local playlists, search and the library.

- Redesigned playlist creation and import dialogs with clearer fields, previews and actions.
- Export local and imported playlists as a compact metadata-only backup. Import old backups too; preserve existing playlists and keep conflicting snapshots separately.
- Search starts only on Enter or the search icon. Only submitted queries enter recent searches.
- Open public artist pages without a Spotify account, with artwork, songs and releases.
- Replace the obsolete Spotify library controls with local/YouTube source filters, working sort and grid/list views. Show account refresh errors and cancellation controls.
- Hide YouTube's podcast-only Episodes for later queue.

Windows validation covers these changes. The installer remains unsigned. Credits and upstream license notices are retained.
