Maintenance update for playback state, metadata and regression tests.

## Fixed

- **Audio-engine shutdown** no longer leaves a blocking event listener holding the runtime open.
- **Reconnection state** clears the old network-wait flag when a new connection starts.
- **Queue selection** keeps the chosen track visible instead of immediately rebuilding from the previous playback state.
- **Local song labels** decode URI-encoded metadata without rewriting real tags containing plus or percent signs.
- **Device identity** distinguishes Cast receivers with the same displayed name.
- **Sign-in error privacy** avoids including untrusted callback paths in error messages.

Unit tests now cover the current native playback queue, YouTube Music search, background playlist additions and interface. Older tests were updated to the supported behavior rather than restoring removed Spotify features.
