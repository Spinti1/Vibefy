# Vibefy 0.4.76

- Resume interrupted YouTube playlist saves using the existing copy. Verify uncertain additions before retrying.
- Evaluate every returned recording candidate, rather than truncating the list before finding the official recording. No extra search request is needed.
- Match equivalent studio releases across album, single and compilation listings, with a small timing tolerance. Artist, incompatible-version and clean-edition checks remain.
- Recognize the original video ID explicitly attached by YouTube to a substituted audio row, instead of retrying an already-saved song.
- Add and verify missing songs before removing obsolete rows. Resuming keeps the existing YouTube order and appends missing songs; a display-order preference no longer marks a complete song transfer as failed.
- Keep the complete local playlist when songs cannot be matched, and report incomplete saves.
- On web and phones, sync an existing YouTube copy instead of creating another playlist. Refresh updates imported YouTube playlists on Home without overwriting local originals.

The Windows installer is not code-signed. Hosted phone changes do not require reinstalling APK/IPA.
