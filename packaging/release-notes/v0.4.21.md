Playback can use a fully verified catalogue result sooner, and combined MP4 cache files can lose their video without changing the audio.

## Fixed
- **Earlier verified playback.** Search responses and watch-page inspections are processed as they arrive. A fully inspected catalogue match with compatible duration can start without waiting for a slower sibling request. Other uploads retain the complete matching checks and ranking. Superseded tasks are cancelled.
- **Lossless audio-only cache.** Supported ordinary AAC MP4 files are compacted in the background after playback receives the original bytes. Encoded audio samples, codec setup, timing and edit tables are preserved. Cache replacement is atomic and skipped if the source file changed or its layout is unsupported. Existing cached files are handled when accessed; audio-only files are left intact. No new executable, codec conversion or bitrate reduction is added.
- **Less repeated disk work.** Identical recording metadata no longer rewrites the match index when replaying a cached direct-source song.
