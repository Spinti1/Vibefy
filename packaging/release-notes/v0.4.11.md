Vibefy 0.4.11 fixes false Windows cache warnings and makes search results usable sooner.

## Fixed

- **Windows redirected caches are counted and cleared correctly.** MSIX virtualization no longer triggers a false path-boundary warning. Linked roots and child junctions remain excluded.
- **Known songs appear while Spotify responds.** Music results arrive independently, with playlists and podcasts fetched when viewed. Successful music can return from cache without waiting for the other categories.
- **Search no longer spends multiple retry windows loading.** Rate limits return promptly while preserving Spotify's cooldown; network searches have a short deadline and a retry action. Available results remain usable.

## Thanks

Spinti for reporting the cache warning and slow search, and the Spotifast contributors.
