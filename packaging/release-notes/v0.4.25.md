Optional music-account connections let you import provider playlists into the same Home view.

## New
- **YouTube Music browser session.** Import your own Music request-header file or ytmusicapi browser.json using the instructions in Settings. Reads saved/private playlists accessible to that session, with paginated imports to Home. No Google OAuth project, Client ID or tester cap. This is an unofficial interface; sessions can expire and service limits still apply.
- **JuiceVault connection.** Browser sign-in uses the documented challenge/verifier handoff. Enter a public profile username to list its public playlists and save selected collections on Home. Private-library and session-refresh endpoints are not documented and are not claimed as supported.
- **Shared source player.** YouTube Music or JuiceVault connections can open the source-player interface without a Spotify account. Spotify remains available independently in Settings. Source playlists retain order and repeated tracks; reimporting updates the local snapshot. These imports do not modify provider playlists.
- **Protected saved sessions.** Music sessions and JuiceVault tokens are protected locally (Windows user-bound DPAPI; system keychain on other supported platforms) and restored at startup. Work runs in the background and can be cancelled. Playback, artwork and other providers do not receive account tokens.
- **Direct JuiceVault playback.** Validated archive IDs resolve to the documented stream endpoint, using the current proxy and the existing bounded audio cache.
