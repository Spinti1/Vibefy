Similar song titles can now qualify for Spotify-to-YouTube playback. Exact titles still rank first when other evidence is equal.

## Fixed
- **Less rigid title matching.** Small spelling differences, spacing changes and reordered words can match without requiring identical cleaned titles. Artist, recording version and duration checks remain active. Numbered sequels and short, different song names remain distinct.
- **Accurate audio format information.** Settings show automatic AAC/M4A playback and its MP4 fallback. The inherited 96/160/320 kbps buttons did not affect this playback engine and have been replaced with the format actually used. Bitrate and duration determine file size; this release adds no MP3 transcoding or format switch.
