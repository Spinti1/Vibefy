Vibefy 0.4.12 moves the main search to YouTube Music and improves imported playlist artwork.

## New

- **Search YouTube Music directly.** All is the default, with separate Songs, Videos, Albums, Artists and Playlists filters, native browsing, more results and saving playable rows on Home. Each selected row plays its exact YouTube source. Main search does not use a Spotify token or developer Client ID.
- **Imported playlists gain matching music artwork.** Opening a saved import or completing a new import progressively looks for the same song's album art. Artist, title, version and duration must agree; video identity and timing remain intact. Artwork is retained with the saved collection.

## Fixed

- **Use primary thumbnails instead of numbered frames.** Import thumbnail selection prioritizes approved music art and primary uploader thumbnails, rather than the last item in an extractor's list. Music CDN art requests a 600 px image.
- **Keep searches responsive.** Successful queries use a bounded two-minute memory cache. New queries cancel old work; errors have a retry action and finite deadlines. YouTube's own cooldowns remain respected.

## Thanks

Spinti for the request, sigma67/ytmusicapi for the public metadata protocol reference (MIT), and the Spotifast contributors.

This is an unofficial YouTube Music integration. Availability depends on the service; Spotify library access retains its existing limitations.
