Vibefy 0.4.51 imports public Spotify playlists without connecting a Spotify account.

- Remove Spotify sign-in, Client ID setup and automatic Spotify credential restoration from the desktop flow. Existing stored grants are retained but are not loaded.
- Paste a public Spotify playlist link on Home. Private playlists and Liked Songs are not supported. The original playlist is unchanged.
- Read public playlist pages in order, preserve repeated songs, reject incomplete/repeated pages and respect service cooldowns. Unavailable or unsupported entries are reported.
- YouTube connection, local playlists and optional YouTube backups remain available.

Public import uses Spotify's public web data; upstream changes or restrictions can temporarily prevent imports. The Windows installer is unsigned. Credits remain in CREDITS.md and the included license notices.
