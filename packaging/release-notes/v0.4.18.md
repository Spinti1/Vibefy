Check for updates directly from the profile menu. Spotify recording choices now show album covers, and undersized startup windows recover their normal layout.

## New
- **Profile-menu updates.** Choose “Check for updates” to check official Vibefy GitHub releases. A newer version opens the existing download and installation dialog. Checking progress, current-version confirmation and failures are shown in the app.
- **Album covers in Spotify recording choices.** Square artwork appears beside each suggested song when adding a source track to a Spotify playlist. Missing artwork uses a placeholder.

## Fixed
- **Usable startup window size.** A tiny window restored by the framework recovers the last valid main-window size. Temporary minimized dimensions and nonfinite saved sizes no longer replace the main layout. The classic mini player and fullscreen are preserved.

## Thanks
Spotifast by Carmine Paolino and contributors provides the original interface, window handling and updater foundation. All existing project, mod and dependency credits remain in CREDITS.md and THIRD_PARTY_LICENSES.txt.

Windows Setup is unsigned. Updates use GitHub HTTPS, published asset size, SHA-256 digest and checksums.txt. Installation preserves layout and uses the current installation folder.
