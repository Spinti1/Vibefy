# Vibefy 0.4.75

- Remove WaveLink from the desktop mod catalogue and retire old enabled installations without resetting account or playlist data. Previously saved source metadata remains readable.
- On phones, remove Cat Jam and align Nyan Cat with the visible seek control, including the expanded player and Jam.
- Fix missing Play/Pause glyphs, failed-playback button state and seek previews. Improve phone player spacing and touch controls while retaining keyboard focus indicators.
- Defer hidden queue rendering and avoid rebuilding unchanged transport icons.
- Add the existing desktop More Lyrics fallback to the web service, with recording metadata checks and provider attribution. Provider access remains external; direct validation of More Lyrics returned HTTP 403, while LRCLIB and YouTube Music remain available as fallbacks.

The phone interface updates through the hosted player; these changes do not require reinstalling the APK or IPA. Physical Android/iPhone validation has not been performed. The Windows installer is not code-signed.
