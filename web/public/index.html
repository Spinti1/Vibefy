PHONE BROWSER

Mobile web player
Beta

The phone version includes music search, a queue, local collections, LRCLIB lyrics and compatible mods. Playback uses the official YouTube player.

Spotify account connection is not enabled yet. Browser Jam uses PeerJS and is separate from desktop LAN sessions. Background playback, EQ and audio-reactive desktop visualizers are unavailable in the public web player.

On your phone: usevibefy.online

Credits & source projects

Vibefy is an independent fork of Spotifast by Carmine Paolino, which provides the native interface and player foundation. Thank you to all original contributors.

Core projects: Rust, egui / eframe, fastframe, librespot, Symphonia, yt-dlp, whisper.cpp / ggml and OpenAI Whisper. Search: ytmusicapi by sigma67 and contributors.

Native adaptations and inspiration: NoahClemmensen/Nyan Bar Synced, kyrie25 and adryd325/Oneko, BlafKing/Cat Jam Synced, xoft122/WaveLink, wairence/Vivy, rolandyangg/Backmusic, Grason Chan/Spotify Spice (Track Peek only), Kyzenkms/Spicetify Jam (independent LAN implementation).

Web: FastAPI, Starlette, Pydantic, HTTPX, Uvicorn, PeerJS and their contributors. Fonts: DM Sans by Colophon Foundry and Space Grotesk by Florian Karsten (SIL OFL). Hosting: Vercel. Windows packaging: Inno Setup. Dependency and asset license notices ↗.
