Your library and privacy

Updated November 6, 2026

Browser storage

Playlists, saved songs, search history and preferences stay in this browser. Only song metadata is saved, not music files. There is no separate Vibefy web account or analytics. Clearing site data removes the local library. Export a backup first; restoring merges playlists without replacing existing ones. The web player cannot read your desktop profile.

Optional Google / YouTube connection

Google handles basic sign-in and shares the profile name shown in this tab. Reading your YouTube playlists is a separate optional permission. Saving or changing a YouTube copy requests additional permission. Short-lived access tokens stay in this tab's memory and are sent directly to Google APIs, not to Vibefy's API or backups. Disconnect clears the session and asks Google to revoke the grant. Local imports remain. Account access depends on Google's permissions and quotas.

Optional JuiceVault connection

If you enter a JuiceVault username and password, our HTTPS API forwards them to api.juicevault.xyz because that service does not permit direct browser API access. We do not save or log passwords or tokens. Your returned access token stays in this tab's memory and is forwarded to JuiceVault for authenticated playlist requests. Disconnect clears it. Avoid connecting on shared devices. Google credentials are never accepted by this adapter.

Public services and playback

Queries, public Spotify/YouTube playlist identifiers and requested artist/recording identifiers go to our Vercel API for public metadata and matching. Lyrics come from LRCLIB or YouTube Music. Playback uses the official visible YouTube or SoundCloud player; JuiceVault recordings load directly from its API. Providers receive connection information and may apply their own cookies, advertising and privacy policies. Cover images load from the source providers. Fonts load from Google Fonts. Hosting providers may retain operational request/IP logs. There is no server-side audio library or playlist database.

Mods and backups

Mod preferences and assets are local to your browser. Backups contain playlist and song information only, without passwords, access tokens or audio. Share backups only when you want to share their playlist metadata. Browser and desktop libraries are separate.

Listen Together

Jam connects through Cloudflare using encrypted HTTPS/WebSockets. Participants do not connect directly or receive each other's IP addresses. Cloudflare processes IP addresses and bounded room metadata: recording identifiers, queue, positions and playback state. Music files and account credentials are never relayed. Transport encryption is not end-to-end encryption. Invitation codes grant listener access; the host uses a separate credential. Rooms expire after six hours or when the host ends them.

Desktop downloads and updates

GitHub hosts downloads and source. Desktop updates verify release asset size and SHA-256. Setup preserves the layout and current installation folder. Installers are unsigned; these integrity checks do not protect against compromise of the publisher's GitHub account.

Your controls

Settings offers metadata backup/restore, clearing the browser library and clearing the shell cache. Removing a local playlist does not delete copies from external accounts. Use GitHub to report problems without posting credentials or private logs. About and credits.
